# 审查来源与局部回滚改进记录

2026-10-18。依据用户新生成海洋、低空、汽车制造三份报告，改进系统而非手修文件。当前完成程序修复，真实模型效果和新稿内容验收尚未完成。

## 变更

1. citations.bind_report_sources 在正文引用清理前，按实际CID绑定本报告已经检索的原始片段。body_agent普通与stream入口传全篇来源，不向写作提示无差别加入全篇材料。不存在的CID仍清理，绑定原文不等于声明被核验支持。多个chunk保留，按已有来源身份去重。
2. review_agent按段落隔离新增未决声明的恢复。段落结构对应、整节信息保留复核有效时，恢复含新未决声明的段落，其他段落修改形成候选。候选最多额外复核一次，沿用审查810秒累计截止和总900秒，必须重新取得声明核验和信息保留结果；失败则保守整节回滚。结构变化、整节信息丢失仍用原回滚。原有未决事实不能因保留其他段修改就被认定解决。
3. 恢复原段后清除相应applied_spans；最终paragraph_restore状态在重复复核完成后确定，避免已回滚却记录为成功。
4. review保留execution_status，调用/协议核对未完成与内容partial分开。事实批次失败历史独立保存，不随正文恢复被原核验覆盖。delivery对修正未采用、事实待确认、重复未解决、来源一致性与调用执行分别说明；旧记录无详情继续有通用提示。整体completed判定没有放宽，Word沿用delivery_reasons显示。
