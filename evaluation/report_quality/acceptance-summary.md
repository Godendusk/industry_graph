# 新生成报告质量实施与验收记录（2026-10-17）

当前结论：生产链路改造已实现并合入原工作目录；内容验收尚未通过，不能宣布“任意新报告已经稳定可交付”。旧四份报告未被人工修稿。本记录将程序验证、真实运行和内容判断分开。

## 已实现

- 确认大纲后连续执行协调、正文、审查、摘要和 Word；文件准备好后下载不重复生成。
- 900 秒累计运行预算跨同步、流式、多次请求与历史传递；网络/模型调用按剩余时间设置本次超时，迟到结果不再作为成功返回。用户请求之间主动等待不计。
- Agentic 初查后先跨节共享既有原文，再对仍缺资料的需求补查；保留来源与片段身份，复核目标需求，不按资料数量算支持程度。
- 全篇协调一次输出有效标题、大纲、研究边界、需求覆盖和具体缺口。允许跨一级合并和收窄；范围无效时保留资料并停止原大纲扩写。
- 显式合并映射同时应用于任务、证据和需求覆盖；被删除且未合并的小节不能继续作为 supported/partial 的依据。
- 事实核对与重复审查拆开；声明超额继续分批，最多两批并发。长报告做全节原文分组检查及跨节候选定位，单批失败不抹去其他完成结果。
- 局部补丁与改后复核保留；复核携带完整新正文、原文及已授权的删减。纯方法/条件分析不需要文章替报告下结论，混合句仍核对具体事实。
- 图谱关系进入核对，但只支持记录关系；仅提取正文实际涉及实体及关系，避免大名单挤掉后部实体。
- 日期/对象/预测与实际的来源疑点接入局部修正。可选择本报告其他章节已召回的来源；只有实际返回的引用移入目标节，改后再次核对，未明确解决仍保留警告。
- 裸 C 编号仅在真实存在的来源中规范化；参考资料按正文实际引用收集，Word 不默认附长命中原文。
- completed 只在范围、正文、审查、摘要和文件处理都满足条件时形成；部分稿首页明确标记。摘要/正文编辑使缓存成稿状态失效。

## 程序验证

受影响集合在原工作目录运行，涵盖 Agentic、范围、预算、协调、正文、审查、引用、摘要、Word 和前端；精确最终数量以本目录 verification.json 为准。并非全仓测试，也不是事实准确率。

针对真实失败补了回归：长输出截断、单批未覆盖、后部声明遗漏、合并后图谱丢失、跨节已有证据未共享、共享后补查问题丢失、来源代号悬空、部分稿冒充成稿、超时阻塞/迟到结果、错误引用借别处来源通过、分析误判、图谱事实绕过检查、重复句位置歧义、补丁复制原文前导句、误报无修改时的独立复核。

## 尚未解决与下一步判断

1. 来源冲突能被发现，但修正模型仍可能只给旧预测补日期，没有把同报告其他处的后续实际状态纳入判断。必须以修改后的内容验证，不能仅以 consistency_resolved 字段认定质量。
2. 事实与分析的语义判断、声明核对结果完整性仍不稳定；部分合理的角色归纳、证据边界被判为 partial，部分混合事实也有漏判风险。已修复具体上下文与绑定问题，仍需用保留题验证泛化。
3. 部分小节重复与独立用途不足。去重已有实际修改，但可定位失败、事实与去重补丁重叠时仍有明确延后项，语法/信息保留复核失败会使修正回滚；不能取消这些保护来提高“通过率”。
4. 范围协调在15节生物制造中仍保留了证据不足的独立章节；最新稿还出现由科研项目申报要求推到食品配料路线普遍工程条件的风险，虽然标注边界，仍不足以完成可靠比较。“可收窄”能力已接入，但收窄决策的实质质量尚未稳定。
5. 模板原有“国资央企问题与建议”要求会诱导摘要增加正文没有的结论。已明确有效范围与正文优先，两个最新摘要均完成一致性修正；这一结果不替代正文验收。
6. 比较表格的 Word 输出尚未实现，本批保留段落对照；不是当前内容验收失败的主要原因。

没有更换模型或生产数据渠道。一次6000 token的思考模式核对探针全部预算用于推理、可见JSON为空，不能据此把全篇审查直接切回思考模式；12000 token探针在15.78秒返回有效JSON、处理了部分分析误判，但仍有行业结论套具体企业的判断风险，仅作诊断，没有据此切换生产模式或宣称全篇质量改善。
