# 第一版报告交付展示实施计划

用户已确认信息分流表并要求直接执行。在既有质量改进 worktree 顺序完成，验证后同步当前运行目录；不提交、不部署、不改历史报告正文。

**Goal:** 正式报告仅呈现研究内容、必要的资料与方法说明及参考资料，生成页面完整保留待核对事项和内部过程。

**Architecture:** Word 导出保持 delivery_state 原有判定，把内部说明作为 API 的 adjustment_notes 返回；从实际引用资料日期与 report_scope.boundary 生成简短方法说明。页面在正文预览外显示交付核对状态和可展开记录，历史保存与恢复携带状态原因。Markdown 与 Word 采用相同信息边界。既有正文的数据条件和局部限制原样保留，不增模型调用或放宽审查通过条件。

**Tech Stack:** Python/python-docx、原生 JavaScript、pytest、Node test runner。

## 检查的具体目的

导出回归用于发现内部记录漏入文档、移除提示后错误放行、或正文限制丢失；发现则修对应导出或状态边界。前端回归用于发现待核对信息不可见、历史恢复丢失、Markdown 泄露记录或导出状态过期；发现则修数据接收与渲染。离线重导出和渲染用于发现真实记录中的元数据误用及版式缺陷；发现则修确定性展示逻辑。无需重新调用模型生成整篇报告。
