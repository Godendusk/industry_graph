# 图谱证据召回接入计划

目标：将已有图谱链接取回的真实 chunk 加入产业报告候选集，并保持行业隔离和引用流程。

实现边界：AI 使用现有 v2 索引的 chunks 表，资讯产业读取当前 Chroma 文本元数据，均只读按 chunk_id 定位；校验资料 ID；缺失、失效链接给出诊断，不自动编造。链接最多取 40 条，与现有候选去重后用现有 reranker 对原始章节问题重排。没有链接时不调用模型也不访问索引。

1. 写临时 SQLite 的失败测试：精确取回、错资料 ID、不跨行业、缺失片段。
2. 实现 graph_evidence_retrieval.py：取回、合并、精排失败回退、上下文重建。
3. 在 coordinator 的候选分配前接入；用 mocked 外部边界测试真实统筹入口。
4. 增加离线候选映射生成器：扫描真实 chunks 的实体全名，只生成 pending 实体提及链接；不把共现当关系证据。
5. 生成具身智能候选映射和可读审核说明；测试通过后交付。

无需社区摘要、新数据库、feature flag、哈希或索引迁移。

完成记录：证据取回、统筹接入、候选生成和真实小样本均已实现。具身智能候选155个实体/266条引用（扫描5000片段）；启用5个实体提及、1条参与环节关系。真实本地reranker已验证；图谱节点选择在连通验证中固定为49，没有外部LLM请求。独立审阅发现的资讯旧词法副本风险已修正为始终读取当前原库。
