# 具身智能纯 Hybrid 与图谱增强验收

目的：补齐上轮具身智能索引READY缺失导致回退legacy_news的运行缺口。

执行：
1. 用现有build_news_hybrid_index.py构建具身智能完整词法索引，复用向量，保留续建记录；原库只读。
2. 完成后调用check_news_index确认READY，失败则根据错误修复或续建，不把回退结果当纯Hybrid。
3. 运行原五个问题，保存基线实际版本、阶段告警、图谱候选、相同reranker控制组、保留和丢弃片段。
4. 阅读差异片段判断支持范围，不把候选数当质量指标。
5. 生成可读验收说明，记录索引规模、运行耗时和仍待领域审核的内容。

本轮不改Word导出、不扩展其他产业、不重新计算向量。
