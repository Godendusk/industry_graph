# 产业报告 Agentic RAG 第三阶段交付说明

日期：2026-10-16。第三阶段后端已实施；第四阶段界面、历史/导出整合与多产业对照尚未开始。

## 交付内容

本阶段只升级产业报告生成及局部重写后的审阅，智能问答不改动。

1. 从正文优先抽取数字、年份、排名、政策条款、企业产品和关系等声明，保留原文、起止位置及段落标识。第一版使用关键内容规则选取候选，每节最多24项；不是全文任意事实的完备抽取，超额明确记录待确认。
2. 将关键声明核对并入现有一轮审阅模型调用，返回有支持、部分支持、不支持、冲突、无法判断。支持记录同时保留报告引用编号、材料/片段身份和逐字摘录；不会把同一资料的任意片段当成当前声明的依据。
3. 对不存在的片段、未引用资料、伪造摘录、遗漏核对及证据截断采取保守状态。当前声明缺少对应片段时不能因为同节其他声明有证据就确定不支持。显式名单的逐字依据不全时需确认；无法可靠对应带修饰语的名单不会授权自动修改。
4. 合并事实修改与原有重复精简要求。重叠、与保留内容冲突时暂缓事实修改，不叠加互相覆盖的补丁。每节最多执行一次局部修改，不新增检索循环。
5. 修正后重核被修改小节，刷新声明位置和引用绑定，同时检查独有事实、限定、计划/已实现状态及有效引用是否保留。新增/变化的声明未通过、复核失败或存在信息损失时恢复原文并待确认。未改动的既有未知声明可以继续待确认，不强制回滚其他已通过修改。
6. 同步/流式正文都使用现有审阅返回的最终正文；局部重写返回新的核对结果，旧结果失效。摘要沿用已有最终正文输入和摘要一致性检查。

## 预算与调用

关键事实核对与原有初次重复审阅共用一次调用。各节证据共用24,000字符预算，每个片段最多展示4,000字符；核对输入按整篇剩余预算纳入，超额保留未知，不挤掉原有审阅。仅发生局部修改时，增加一次修改后核对；现有重复修改复核仍复用。不新增 Agent 框架、独立模型服务或开关。
